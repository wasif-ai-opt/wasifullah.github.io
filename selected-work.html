Evolution of self-learning composite dispatching rules

MATLABGenetic programming Core PhD project

An evolutionary hyper-heuristic framework that automatically generates composite dispatching rules for dynamic job shop scheduling. The system evolves interpretable rule expressions from shop-floor attributes and evaluates them in a stochastic discrete-event simulation with machine breakdowns and rush orders. PythonDiscrete-event simulation Research infrastructure
