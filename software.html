Python Simulation

Dynamic scheduling simulation environment

Discrete-event simulation · research infrastructure

A configurable discrete-event simulation environment for dynamic manufacturing systems, used to benchmark dispatching rules and learning-based schedulers under controlled stochastic conditions — multiple shop configurations, arrival processes and disturbance models including machine breakdowns and rush orders.

MATLAB Optimization

Greedy-assisted TLBO for hybrid flow shop scheduling

Metaheuristics · cost-oriented scheduling

Implementation of the greedy-assisted teaching-learning-based optimization algorithm for cost-based hybrid flow shop scheduling, published in Expert Systems with Applications (2025). Includes problem instances, cost models and experiment scripts.

MATLAB · Python Benchmarking

Metaheuristics benchmarking suite

Comparative study · PSO · DE · TLBO · GA

Benchmarking code comparing classical dispatching rules, metaheuristics and learning-based approaches on standard scheduling problems, with attention to solution quality, computational cost and robustness to dynamic changes.

Python Evolutionary

Evolution of self-learning dispatching rules

Genetic programming · hyper-heuristics · core PhD project

An evolutionary hyper-heuristic framework that automatically generates composite dispatching rules for dynamic job shop scheduling. The system evolves interpretable rule expressions from shop-floor attributes and evaluates them in a stochastic discrete-event simulation.
